# Contributing

Built something with Spinel? Open a pull request that adds it.

## What fits

- A program, library or tool that compiles with Spinel today. Say which Spinel commit or release you checked it on in the pull request.
- Public source with a README that explains how to build it.
- Issue reproducers and one-off bug demos belong in the Spinel issue tracker, not here.

## How to add an entry

- Put it in the section that fits best, at the end of that section.
- Use this format: `- [Name](link) - Short description ending with a period.`
- Keep the description to one line and say what the project does, not how great it is.
- Link a live demo next to the entry if there is one.

## Showcase

The showcase at the top is for projects with something to see: a screenshot, a photo of the hardware, a browser demo. If your project has one, propose it in the pull request with the image. Images live in `assets/` (PNG or JPEG, at most 1280 px wide) or are linked from your own repository.
